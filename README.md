# 0xSac Web Platform

Static web delivery engine for 0xSac cyber exercise blueprints, threat scenarios, and detection validation guides in Northern California.

**Status:** Staging — Date TBD

## Architecture

- Astro (Static Site Generation)
- Tailwind CSS
- GitHub Actions
- GitHub Pages (`0xsac.com`)

## Local Development Quickstart

```bash
npm install
# or
npm ci

npm run dev
npm run build
npm run preview
```

## Site Routing Layout

- `/` — Home (Exercise blueprints, current scenarios in design, partner inquiries)
- `/about` — About (Vision, Mission, and Operational Boundaries)
- `/resources` — Technical notes, detection guides, and range architecture patterns
