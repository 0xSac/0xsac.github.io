0x0100 // Hands-on Live-Fire & CTF

Track 1 Operator Jump-Kit

Use only on authorized exercise assets. Preserve evidence before changing hosts; never paste secrets or case artifacts into public channels.

01 // Baseline

Host Triage & Hardening Baseline

  • Linux: Review /etc/passwd for unexpected UID 0 accounts; inspect sudoers and included files. Check auditd status, authentication logs, Nginx configuration and access/error logs.
  • Active Directory: Review privileged membership, krbtgt rotation history, and duplicate or unexpected Kerberos SPNs. Coordinate any dual reset of krbtgt with the directory recovery lead; do not reset during triage.
  • Sysmon: Correlate Event IDs 1 (process creation), 3 (network connection), and 11 (file creation). Network logging depends on the deployed configuration.
awk -F: '$3 == 0 {print $1}' /etc/passwd
sudo visudo -c
sudo systemctl status auditd --no-pager
sudo nginx -t

# Windows: duplicate SPNs (authorized domain)
setspn -X
Get-WinEvent -FilterHashtable @{
  LogName='Microsoft-Windows-Sysmon/Operational'
  Id=1,3,11
} -MaxEvents 50

DFIR & Memory Analysis Cheatsheet

Work from hashed copies of acquired memory and packet captures. Plugin availability depends on OS, symbols, and the installed Volatility 3 release; confirm with vol.py --help. Treat hashdump output as sensitive credential material.

python vol.py -f memory.raw windows.hashdump

0x0200 // EDS Leadership

04 // Notification timeline

California Breach Clock Guide

  1. Discovery: Record discovery time, evidence, affected services, data ownership, and counsel's notification assessment.
  2. Immediate coordination: Assign incident/legal leads; coordinate threat intake with Cal-CSIC. Intake is not a substitute for statutory notices.
  3. Resident notice: Review Civil Code § 1798.82, including the 2026 30-calendar-day discovery deadline and permitted delays. Public agencies must separately assess § 1798.29.
  4. Attorney General: For notices to more than 500 California residents under § 1798.82, review the 15-calendar-day deadline after resident notification and AG submission requirements.
  5. Federal thresholds: Assess sector rules and CISA/CIRCIA coverage. The framework specifies 72 hours for covered incidents and 24 hours for ransom payments; verify final-rule effective dates and applicability before treating these as operative deadlines.
